# CNC Machining Services Website

Одностраничный сайт услуг токарно-фрезерных работ с ЧПУ в Новосибирске.

## 🚀 Технологии

- **PHP 8+** - базовая логика, подключение секций
- **Stylus** - препроцессор для стилей, компонентный подход
- **JavaScript (ES6)** - анимации и интерактив
- **Gulp** - сборка и минификация

## 📦 Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd cnc-website
```

2. Установите зависимости:
```bash
npm install
```

## 🛠️ Разработка

### Запуск в режиме разработки

```bash
npm run dev
```

Эта команда:
- Компилирует Stylus в CSS
- Объединяет и минифицирует JavaScript
- Запускает BrowserSync для live reload
- Отслеживает изменения в файлах

### Сборка для продакшена

```bash
npm run build
```

Эта команда создаст минифицированные файлы в папке `assets/`:
- `assets/css/main.min.css` - минифицированный CSS
- `assets/js/main.min.js` - минифицированный JavaScript

## 🔧 Настройка

### Изменение цветов

Отредактируйте файл `src/stylus/_variables.styl`:

```stylus
$color-primary = #dc0000        // Основной цвет
$color-secondary = #8b0000      // Вторичный цвет
$color-dark = #0a0a0a           // Темный фон
```

### Добавление новых секций

1. Создайте папку в `src/components/`
2. Добавьте файлы `component.php` и `component.styl`
3. Импортируйте стили в `src/stylus/main.styl`
4. Подключите компонент в `src/index.php`
